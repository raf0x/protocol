## Agent skills

Engineering skills support the existing process in `docs/agent-os/WORKFLOW.md`;
apply them selectively according to task complexity.

The Product Owner (Rafael) has ultimate authority over business objectives,
product acceptance, major scope changes, and release authorization. ChatGPT,
as Product Orchestrator, handles product strategy, requirements, prioritization,
decisions within the Product Owner's approved direction, and engineering
coordination. Codex handles engineering execution, implementation, testing,
debugging, and technical review within explicitly authorized scope and repository rules.

### Issue tracker

Use GitHub Issues in `raf0x/protocol`. See `docs/agents/issue-tracker.md` when
reading or publishing tickets or specs.

### Triage labels

Preserve existing labels and use the role mapping in `docs/agents/triage-labels.md`
when triaging issues.

### Domain docs

Use a single-context layout and the existing decisions register. See
`docs/agents/domain.md` when exploring domain terminology or architecture decisions.
